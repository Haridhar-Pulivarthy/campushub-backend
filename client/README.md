# CampusHub client

React + TypeScript + Vite frontend for the CampusHub backend. Setup, startup,
the demo user, and verification steps are in the repository root `README.md`;
frontend coding rules are in the root `CLAUDE.md` (§4).

```powershell
npm install
npm run dev        # http://localhost:5173 — proxies /api to http://localhost:3000
npm run typecheck
npm run lint
npm run build
```
